# HANDOFF.md 갱신

`HANDOFF.md`는 세션 간 인계 문서이자 **여러 PC에서 git으로 공유하는 정본**이다. 규칙 정본은 `CLAUDE.md`의 "⛔ 핸드오프 확인 규칙"과 `HANDOFF.md` 머리말 주석이며, 이 스킬은 그 규칙을 실행하는 절차다.

## 1. 사실 확인 먼저 (추측 금지)

갱신 전에 **실제로 확인한 값만** 쓴다. 확인하지 않은 것은 "미확인"으로 명시한다.

```bash
git log --oneline -10 && git status --short
ls gate_report_*.md | wc -l          # 게이트 리포트 누적 수
ls -la dropweb/*.zip | tail -3        # 가이드 zip (최신 판별은 md/landpress.md §5-1 0단계 — 파일명·mtime만으로 판단 금지)
```

- **위키 버전·용어집 버전은 토큰이 있을 때만** 라이브로 확인한다(캐시 금지). 토큰이 없으면 이전 값에 `(미확인)`을 붙이고 갱신하지 않는다.
- 스케줄 태스크를 언급할 때는 `mcp__scheduled-tasks__list_scheduled_tasks`로 등록 여부를 확인한다 — 문서에만 있고 실제로 없는 경우가 있었다.

## 2. 섹션별 갱신 규칙

| 섹션 | 처리 |
|---|---|
| 프로젝트 정보 | 링크·버전이 바뀐 항목만 수정. 새 작업 대상(위키 페이지 등)이 생기면 **관련 링크에 추가** |
| 현재 상태 | **덮어쓴다.** "마지막 갱신: YYYY-MM-DD (세션 #N)" + 지금 상태 + 이번 세션 요약(커밋 수·origin 최신 SHA 포함) |
| 다음 할 일 | 완료분은 삭제하지 말고 세션 기록으로 **이동**. 새 할 일 추가. `사용자 액션 대기` / `Claude 실행 대기` / `차단 요소` / `사용자 결정으로 종결` 구분 유지 |
| 주요 결정 사항 | 이번 세션의 결정을 **맨 위 행**에 추가(날짜·결정·이유). 기존 행 수정 금지 |
| 최근 세션 기록 | 맨 위에 `### YYYY-MM-DD — 세션 #N: 제목` 추가. **최대 5개** 유지, 넘치면 가장 오래된 항목을 "아카이브 요약"으로 1~2줄 압축 이동 |
| 컨텍스트 노트 | 다음 세션이 반복 조회할 정보(자주 쓰는 조회·산출물 위치)만 최신화 |

**실수·회귀는 반드시 남긴다** — 무엇을 틀렸고 어떤 규칙·검사기로 차단했는지까지. 이 프로젝트는 실수를 규칙·검사기로 전환하는 것이 재발 방지의 정본이다.

## 3. 품질 기준

- **300줄 이내** (`wc -l HANDOFF.md`로 확인). 넘으면 오래된 세션 기록부터 압축한다.
- 경로·커밋 SHA·명령어를 포함해 다음 세션이 바로 실행할 수 있게 쓴다.
- **"왜"를 먼저** 쓴다. 결정에는 근거, 보류에는 대기 대상.
- 추측과 사실을 섞지 않는다(`(추정)`·`(미확인)` 표기).

## 4. git 공유 (필수 — 여러 PC 인계 경로)

갱신 후 커밋·푸시한다. 푸시하지 않으면 다른 PC에서 이전 상태를 본다.

```bash
git add HANDOFF.md && git commit -m "docs(handoff): <한 줄 요약>" && git push
```

- 같은 세션에서 규칙 문서(`md/`)·스킬(`.claude/skills/`)·에이전트(`.claude/agents/`)를 바꿨으면 **함께 커밋**한다 — 이 경로들이 PC 간 공유 대상이다.
- `.claude/settings.local.json`은 기기별 설정이라 git에 올리지 않는다(`.gitignore`).
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`를 넣는다.

## 하지 말 것

- 완료된 "다음 할 일"을 **삭제**(세션 기록으로 이동해야 이력이 남는다)
- 확인하지 않은 위키·용어집 버전을 새 값으로 적기
- "사용자 결정으로 종결" 항목을 다시 할 일로 되살리기
- 세션 기록을 6개 이상 쌓기
