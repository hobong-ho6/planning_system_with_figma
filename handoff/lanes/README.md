# lanes/ — 전역 자원 점유 락

**파일이 존재하면 그 자원은 점유 중이다.** 표 한 줄을 여럿이 고치면 충돌하므로, 세션마다 **파일 1개**를 만들고 지운다(머지 충돌 구조적으로 0).

```bash
ls handoff/lanes/
```

## 락이 필요한 전역 자원 (이것만)

`guide/` · `dropweb/*.zip` · 용어집 `web3_xlt_json` · `md/**` · `scripts/**` · `templates/**`

프로젝트 전용 자원(자기 위키 페이지·`xlt/` 엑셀·`reports/gate/`)은 담당자가 단일하므로 락 불필요.

## 규칙

1. **시작**: 전역 자원을 만지기 전에 `ls handoff/lanes/`로 남의 점유를 확인한다. 같은 자원이 잡혀 있으면 **작업하지 말고 사용자에게 보고**한다.
2. **생성**: `{YYYY-MM-DD}-{person}-{주제}.md` 로 만들고 **즉시 커밋·푸시**한다(로컬에만 있으면 락이 아니다).
3. **해제**: 작업을 끝내거나 중단하면 파일을 **삭제**하고 푸시한다. 중단 시에는 삭제 전에 재개 지점을 프로젝트 파일의 WIP에 남긴다.
4. `dropweb/`은 `.gitignore` 대상이라 **zip은 복구 불가**다 — 이 자원의 락을 특히 지킨다(2026-08-10 v23 무음 덮어쓰기 전례).

## 파일 내용 (20줄 이내)

```markdown
- 세션: #{N} · {person} · `{hostname}`
- 시작: {YYYY-MM-DD HH:MM}
- 점유 자원: {guide/ + dropweb/web3_planning_v26.zip}
- 목적: {한 줄}
- 재개 지점: {중단 시에만}
```
