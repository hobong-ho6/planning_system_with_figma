## (d) 추가 개선·제안 (권장 — 임의 적용하지 않음)

### (d-1) 용어집 보완

`상품권`(MY탭 메뉴명) · `포인트` · `유효기간` · `할인`이 미등재다. 특히 **`상품권`은 화면 메뉴명**이라 XLT와 표기가 갈리면 사용자가 혼동한다. 사용자 지시대로 전체 번역 완료 후 일괄 등재하며, 권장 표기는 실사용 실측 후 제출한다.

### (d-2) 추가 개선 제안

1. **클리닉 카드 문구 확정** — 제안값을 채웠다. Figma 원본은 여전히 1번 카드 문구가 복붙된 상태라 **디자인 반영이 필요**하다
2. **`useNow[].imageUrl` 언어별 분기** — 사용자 안내대로 STEP 이미지는 언어별로 달라질 수 있다. 현재 5개 언어 모두 **같은 URL**이며, 언어별 이미지가 준비되면 해당 로케일 JSON의 `imageUrl`만 교체하면 된다
3. **`targetUrl` 미정 4건** — `prepare` 카드 3개 + `banner` 1개가 빈 문자열이다. 링크 라벨(「인기 상품 보기」·「JPYC 계좌 연동하기」)이 노출되므로 URL이 비면 클릭이 동작하지 않는다
4. **FAQ 분리 확정** — 기존 `faqRef`가 가리키던 `clinic_detail_common` 필드는 **실존하지 않는다**(UIT `k_pick_clinic_common_info`의 실제 필드는 `faq`이며 UIT 프로젝트 전용). 참조를 쓰려면 FE가 문자열을 직접 파싱해 **다른 프로젝트**를 추가 호출해야 하므로, 사용자 확정으로 **별개 콘텐츠로 분리**했다. 클리닉 FAQ(UIT 9건)와 서비스 안내 FAQ(LV 8건)는 이제 독립적으로 관리한다
5. **여행 예약 FAQ 없음** — 정책 근거를 확보하지 못해 해당 영역 항목이 없다. 서비스 안내 카드 3개 중 하나가 「K뷰티･인기 여행 상품 예약」이므로 관련 문항 추가 검토 권장
