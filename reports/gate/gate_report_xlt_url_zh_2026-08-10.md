**교정 대상 없음.** 이 작업은 **zh 번역만** 고치며 ko 원문(`요청하신 페이지를 찾지 못했습니다.\nURL을 다시 확인해 주세요.`)은 맞춤법·띄어쓰기·표기 모두 정상이라 변경하지 않았다.

## 2단계: 용어집 위반 검증

### 위반 확정 근거

용어집 `exceptions` **#3 `*URL*`** 은 **5개 언어 모두 `URL` 원어 유지**로 등재돼 있다(`exception_type: technical`). zh만 `網址`로 번역해 위반했다.

| 언어 | 값 | 판정 |
|---|---|---|
| ko | `…URL을 다시 확인해 주세요.` | ✓ 준수 |
| ja | `…URLをもう一度ご確認ください。` | ✓ 준수 |
| en | `…Please check the URL and try again.` | ✓ 준수 |
| th | `…โปรดตรวจสอบ URL แล้วลองอีกครั้ง` | ✓ 준수 |
| **zh** | `…請再次確認**網址**是否正確。` | ❌ **위반 → 수정** |

### 변경 내용

```
before  無法找到您請求的頁面。\n請再次確認網址是否正確。
after   無法找到您請求的頁面。\n請再次確認 URL 是否正確。
```

**라틴 약어 좌우 공백은 실측 다수를 따랐다** — `Unifi` zh_TW 전수에서 한자↔라틴약어 경계는 **띄움 507건(85%) / 붙임 92건(15%)** 이다. 임의 판단이 아니라 등록값 관행에 맞췄다.

### 의미 검토 (`md/translation_validation_guide.md`)

`確認網址是否正確` → `確認 URL 是否正確`. **동사(`確認`)·문형·경어 수준 모두 불변**이고 목적어 명사만 교체돼 의미 변화가 없다. ko `다시 확인해 주세요` ↔ zh `請再次確認…是否正確`의 대응도 그대로 유지된다.
