## 5. (d) 추가 개선·제안 (권장 — 임의 적용하지 않음)

### (d-1) 용어집 보완 권장

1. **`대표 지갑` 등재 검토** — 이 기능의 핵심 개념인데 **시스템 전체 실사용 0회**(신규 개념)라 표기 정본이 없다. 이번에 `대표 지갑`(띄어쓰기)으로 정하고 en `main wallet` / ja `代表ウォレット` / zh `主要錢包` / th `กระเป๋าหลัก`로 통일했다. 등재해 두면 이후 화면에서 흔들리지 않는다.
2. **`전송/송금` 정리** — 원문이 「송금」(`대표 지갑으로 자산 송금`)과 「전송」(`전송하기`·`전송 중`)을 섞어 쓴다. 용어집에는 `송금`(send/送金/轉帳/ส่ง)만 있고 `전송`은 없다. 이번 번역은 언어별로 한 동사(ja `送金`·zh `轉帳`·th `โอน`)로 통일했으나, **ko 원문의 「송금/전송」 혼용 자체를 정리하는 편이 근본적**이다.

> ⚠️ 등재는 **A/B 실측 후** 판단해야 한다(이 저장소 전례). **이번 작업에서는 용어집을 건드리지 않았다** — 사용자 지시(2026-08-14 「교체하지 말고 우선 그대로 둬」)에 따라 **v4.7 그대로**이며, 기획자 가이드 동반 갱신 대상도 아니다.

| 지갑 있는 경우 / 없는 경우 | `코인만 합산` vs `코인에 한해 합산` | **같은 의미를 두 표현으로 씀** → 원문 통일 요청(현재 1키로 통합) |
| 없는 경우 | `‘전송하기' 를` | 따옴표 짝 불일치 + 조사 앞 공백 |
| 없는 경우 | `계정으로  매일` | 이중 공백 |
| 전 화면 | `대표지갑` / `대표 지갑` 혼용 | 원본도 띄어쓰기로 통일 |
| 전 화면 | `이자혜택`·`지갑생성`·`SNS계정`·`여러개`·`Kaia wallet` | 띄어쓰기·브랜드 표기 교정 |
| 전 화면 | 마침표/느낌표 정책 | 현재 유형별로 갈림 — 정책을 확정하면 일관 적용 |

### (d-3) 후속 처리 (사용자 액션)

- **XLT 시스템 업로드는 사용자가 수행**한다(쓰기 API 없음). 대상 서비스는 **`Kaia Wallet`**.
- **앱 키스페이스가 별도라면** 업로드 타겟(디바이스)을 확인해야 한다 — 읽기 API에는 `WEB BROWSER`만 노출된다.
