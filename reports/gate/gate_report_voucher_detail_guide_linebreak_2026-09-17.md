| 점검 항목 | 결과 |
|---|---|
| **`<span>` 마크업 보존** | ✅ **핵심** — Figma AS-IS/TO-BE에는 `<span>`이 **빠져 있다**. 적힌 그대로 등록하면 강조 스타일이 소실되므로 **라이브 마크업을 보존한 값**으로 반영했다. 각 셀 `<span>…</span>` **1쌍 균형** 확인 |
| **개행 위치 — 태그 경계 침범 여부** | ✅ en은 `your` 뒤(= `<span>` **바깥**, span 전체가 2행으로), ja는 `決済と` 뒤(= `</span>` **뒤**). 둘 다 태그를 가르지 않음 |
| **개행 표기 관례** | ✅ **실제 개행 문자(LF)** 사용. 실측: 레지스트리 전체는 실제 개행 881셀 / 리터럴 `\n` 150셀로 혼재하나, **`UF_voucher*` 계열은 실제 개행 55셀 · 리터럴 0셀** → 계열 선례를 따름 |
| ja 개행 자연성 | ✅ 조사 `と` 뒤 = 문절 경계. 행두 `お伝えください。` 정상(금칙문자 행두 시작 없음) |
| en 개행 자연성 | ✅ `your` 뒤 = 한정사–명사구 경계. 2행 `mobile voucher`가 강조 단위와 일치 |
| 치환자(UIT `{{0}}`) | ✅ 해당 없음(변수 미포함) |

| 문장부호 | ✅ ja 종결 `。` 유지, en 종결부호 없음 유지 — 변경 전후 동일 |
| 앞뒤 공백·중복 공백 | ✅ 개행이 기존 공백을 **대체**(공백+개행 이중 없음) |
