### (d-2) 추가 개선·제안 안내

1. **`상담 문의`가 Figma에 없다** — 개선 프레임 136 TEXT 노드 중 0건. 위키·XLT에만 존재하는 문구이므로, 디자이너에게 **대표 시술 가격 슬롯의 미정 상태 표기를 Figma에 반영**해 달라고 요청할 것을 권장한다(향후 전수 추출 시 누락 방지).
2. **`리쥬란힐러` ↔ `리쥬란 힐러` 표기 통일** — 같은 `menu` 필드 안에서 갈린다. Figma 원문도 갈려 있어 **원문 정리 후 통일**을 권장(제품명이므로 `리쥬란 힐러` 쪽이 표준 표기).
3. **브릿지 프레임 원문 정리 2건** (`71241:9154`, 이번 범위 밖) — ⓐ 힐링 안과 태그가 `라식`·`렌즈삽입술`·**`라식`**(중복. 첨부 이미지는 `정밀검사`) ⓑ 헤드라인 `안전한 시력 교정을 찾고있다면` → **`찾고 있다면`**(띄어쓰기). 첨부 이미지(`시력 교정을 고민하고 있다면`)와 Figma 원문이 달라 **어느 쪽이 최신인지 확인 필요**.
4. **`menu` 확장분의 5개 언어 확장 미결** — 현재 ko 단독. 핸드오프 P2 「병원별 3필드 다국어 확장」과 같은 사안이며, tag가 자유 텍스트(시술 상품명)라 **ⓐ 사람 입력 ⓑ ko 폴백** 결정이 필요하다. 확정 시 `menu_{locale}.json` 5종으로 확장 + 게이트 재실행.
5. **필드 배치** — 이 카드는 **브릿지 페이지**(`(Unifi mini) 브릿지페이지` 「내 고민에 맞는 클리닉」) 요소인데 `menu`(상세페이지 대표 시술) 필드에 실린다. 이미 `bridge_info` 필드가 있어, FE가 **상세 필드를 브릿지 화면에서 읽는 구조**가 된다. 사용자 지시대로 `menu`에 넣었으나 `bridge_info` 이관 검토를 권장한다.
6. **`menu` 로컬 산출물 ↔ 실등록값 불일치 2건** — 사용자가 제시한 실등록 JSON과 git 추적 `landpress/menu_ko_KR.json`이 다르다. ⓐ `price`: 실등록 **문자열** `"¥19,999~"` ↔ 로컬 **오브젝트** `{amount,currency,from}`(핸드오프 P2 「FE 협의」 미결 제안본) ⓑ 구분자: 실등록 `･`(U+FF65, Figma 원문 동일) ↔ 로컬 `·`(U+00B7, 원문 교정 반영본). **로컬 파일을 실등록값에 맞출지** 결정이 필요하다.
7. **en 라벨 길이** — `Price on consultation`(21자)이 가격 슬롯(우측 정렬, `¥19,999~` 9자 기준) 폭을 넘을 수 있다. 잘림이 우려되면 `Consult for price`(17자) 또는 `On consultation`(15자)로 축약 가능.
