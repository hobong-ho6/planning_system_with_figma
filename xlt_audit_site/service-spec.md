## 페이지별 상세 기능

| UI 요소 | 동작 |
|---|---|
| **sticky 탭 내비게이션** | 10개 섹션 앵커. 좁은 화면에서는 가로 스크롤. `IntersectionObserver`로 현재 섹션 탭이 강조된다(스크롤 스파이) |
| **요약 카드** | 상단 색 띠로 심각도 구분(빨강=P0 · 주황=주의 · 초록=오탐 · 파랑=중립). 수치는 전부 `data.js`에서 계산 |
| **서비스 심각도 막대** | P0/P1/P2를 서비스별 전체 이슈 대비 비율로 3분할. 절대 건수는 범례에 병기 |
| **nbsp 칩 목록** | 63키를 칩으로 나열하고 오염된 언어 코드를 빨강으로 덧붙인다. 서비스 필터 버튼(전체/DP/UF/KW) |
| **구 표기 규칙 카드** | `언어 · 건수 · before → after · 출처 서비스`. 건수 내림차순 |
| **구 표기 전체 표** | 49행. `before`의 금지 표기는 <span style="color:#d1363b">취소선 빨강</span>, `after`의 대체 표기는 <span style="color:#2e7d55">초록</span>으로 하이라이트 — 무엇이 바뀌는지 한 줄에서 보인다. 서비스 필터 |
| **탐지 매트릭스** | 5×5(자기 자신 5칸 제외 20조합). ✅ 자동 P0(15) / P1 부분 탐지(1) / ❌ 미탐지(4). 좁은 화면에서 가로 스크롤 |
| **사각지대 카드** | ①②③ 각각 `원인 / 결과 / 보완 방법` 3단 정의 목록 |
| **번역 누락 막대** | 서비스별로 미번역 언어(ko/ja/th/zh)를 누적 막대로. 세그먼트 안에 건수 표기 |
| **긴 목록 표** | 110행·14행 표는 `max-height 480px` 내부 스크롤 + sticky 헤더 |
| **벤 다이어그램** | 인라인 SVG. Unifi 2,130 ∩ Dapp Portal 1,596 = 공통 335, 값 상이 151 |
| **프리픽스 막대** | 값이 갈리는 151키의 프리픽스 분포(`UF_` 87 등) |

## 데이터 구조

`data.js`가 전역 `AUDIT` 객체 하나를 노출한다. **수치는 사람이 옮겨 적지 않고** 원본에서 재계산해 생성한다 —
생성기: `scratchpad/gen_audit_data.py` (입력: `fetch_xlt_registry.py` 산출 레지스트리 3종 + `scripts/glossary.json`,
검증: `scripts/verify_xlt_glossary.py`의 `run_validation`·`build_proposals`를 그대로 호출).

| 키 | 내용 |
|---|---|
| `glossary` | 용어집 버전·terms·exceptions·deprecated 수 |
| `services[]` | `name · version · keys · p0 · p1 · p2 · proposals` |
| `proposals[]` | 구 표기 치환 제안 49건 — `service · key · lang · before · after · rule · note` |
| `nbsp[]` | nbsp 오염 63키 — `service · key · langs[]` |
| `untranslated[]` | 번역 누락 후보 110건 — `service · key · missing[] · vals{}` |
| `jazh[]` | ja==zh 동일 셀(CJK 5자 이상) 4건 — `service · key · value · cjk` |
| `keyNames[]` | 키 이름 이상 3건 — `service · key(repr) · issues[]` |
| `korean[]` | 한국어 원문 오류 14건 — `service · key · type · detail` |
| `falsePositives{}` | 오탐 유형별 건수 |
| `divergence` | `unifi · dapp · common · diff · prefixes[] · samples[]` |

`script.js`가 이 객체만 읽어 DOM을 만든다. **HTML에는 수치를 하드코딩하지 않는다**(단, 프로즈 성격의 판정문·확인 필요 9건 표는 정적 마크업).

## 디자인 가이드

| 항목 | 값 |
|---|---|
| 컬러 | CSS 변수. P0 `#d1363b` · P1 `#c17d10` · OK `#2e7d55` · 강조 `#2f5bd7`. 심각도는 **색 + 텍스트 라벨을 함께** 써서 색만으로 정보를 전달하지 않는다 |
| 폰트 | Inter + Noto Sans KR (Google Fonts CDN). 코드·키 이름은 시스템 모노스페이스 |
| 레이아웃 | 최대 폭 1,080px 중앙 정렬. 카드/그리드는 `auto-fit minmax()`로 자동 열 조정 |
| 반응형 | 720px 이하에서 벤 1열·언어 라벨 세로 배치. **360px에서 가로 스크롤 0** 확인. 넓은 표·매트릭스는 자체 컨테이너 내부에서만 가로 스크롤 |
| 다크 모드 | `prefers-color-scheme: dark` 대응. 라이트/다크 양쪽에서 심각도 색 대비 확인 |
| 접근성 | 벤 SVG에 `role="img"` + `aria-label`. sticky 표 헤더 |

## 외부 연동

| 종류 | 대상 | 용도 |
|---|---|---|
| CDN | `fonts.googleapis.com` | Inter · Noto Sans KR |

그 외 외부 라이브러리·API 호출 **없음**. 차트는 CSS와 인라인 SVG로 직접 구현했다(런타임 네트워크 의존 최소화).
