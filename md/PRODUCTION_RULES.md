# ⚠️ 프로덕션 환경 필수 규칙

**이 시스템은 실제 프로덕션 환경에서 사용됩니다.**

데모/테스트/샘플링 모드는 절대 금지되며, 모든 데이터를 완전하게 처리해야 합니다.

---

## 🚫 절대 금지 사항

### 1. 샘플링 금지

**❌ 금지:**
- "처음 N개만 처리"
- "일부 화면만 처리"
- "대표적인 몇 개만"
- "테스트로 몇 개만"
- "예시로 일부만"

**✅ 필수:**
- 모든 텍스트 완전 처리
- 모든 화면 완전 처리
- 모든 언어 완전 번역

### 2. 일부 언어만 번역 금지

**❌ 금지:**
- "한국어, 영어만 먼저"
- "나머지 언어는 나중에"
- "주요 언어만"

**✅ 필수:**
- ko_KR, ja_JP, en_US, th_TH, zh_TW 모두 필수
- 5개 언어 동시 완전 번역

### 3. 검증 생략 금지

**❌ 금지:**
- "빠르게 진행하기 위해 검증 건너뛰기"
- "나중에 검증"
- "간단히 확인만"

**✅ 필수:**
- md/check.md의 3단계 검증 필수
- P0/P1/P2 분류 후 사용자 확인

### 4. 데모 모드 금지

**❌ 금지:**
- "데모로 보여드리기 위해"
- "예시로 생성"
- "테스트용으로"

**✅ 필수:**
- 항상 프로덕션 품질로 생성
- 실제 서비스 배포 가능한 수준

### 5. 간소화 처리 금지

**❌ 금지:**
- "간단한 버전으로 먼저"
- "절차를 줄여서 빠르게"
- "핵심만 간소화해서 처리"
- 가이드(md/)에 정의된 Step을 임의로 축약·통합·생략
- 산출물 구조(엑셀 시트, data.js 필드 등)를 임의로 단순화

**✅ 필수:**
- md/ 가이드에 정의된 모든 Step을 정의된 순서·내용 그대로 수행
- 산출물은 가이드에 명시된 형식·구조를 완전하게 충족
- 절차 변경이 필요하면 임의로 간소화하지 말고 사용자에게 먼저 확인

## ✅ 필수 수행 사항

### 1단계: 번역

| 항목 | 필수 사항 | 확인 방법 |
|------|----------|----------|
| 텍스트 추출 | 모든 화면의 모든 텍스트 | `총 {N}개 텍스트 추출` 보고 |
| 언어 번역 | 5개 언어 모두 | ko, ja, en, th, zh_TW 모두 완료 확인 |
| 검증 | 3단계 검증 완료 | P0 0건 확인 |
| 엑셀 생성 | 모든 XLT Key 포함 | 엑셀 행 수 = 텍스트 수 확인 |

### 2단계: 프로토타입

| 항목 | 필수 사항 | 확인 방법 |
|------|----------|----------|
| 화면 수집 | 프로토타입 플로우의 모든 화면 | `총 {N}개 화면 수집` 보고 |
| 인터랙션 | 모든 reactions 추출 | `총 {N}개 인터랙션` 보고 |
| 텍스트 노드 | 모든 TEXT 노드 매핑 | 화면별 개수 vs Figma 개수 비교 |
| XLT Key | 1단계의 모든 Key 매핑 | data.js에 누락 없음 확인 |
| 코멘트 | 모든 코멘트 포함 | comments[] 배열 확인 |
| Variant | 모든 CHANGE_TO 처리 | variantSwaps[] 배열 확인 |

### 3단계: 위키

| 항목 | 필수 사항 | 확인 방법 |
|------|----------|----------|
| 화면 이미지 | 모든 화면 이미지 | 이미지 개수 = 화면 개수 |
| 번역표 | 모든 XLT Key + 5개 언어 | 표 행 수 확인 |

## 📋 사용자 확인 프로토콜

### 시작 전 확인

**템플릿:**
```
=== 프로덕션 환경 작업 확인 ===

이 Figma 파일을 분석한 결과:
- 총 {N}개 화면
- 총 {M}개 고유 텍스트
- 총 {K}개 인터랙션

다음을 진행합니다:
✓ 모든 텍스트를 5개 언어(ko, ja, en, th, zh_TW)로 완전 번역
✓ 모든 화면과 인터랙션을 포함하여 프로토타입 생성
✓ 3단계 검증 수행 (P0/P1/P2)

예상 소요 시간: {T}분

전체 처리를 진행하시겠습니까? (Y/N)
```

### 진행 중 보고

**각 단계 완료 시:**
```
✓ Step X 완료: {설명}
  - 처리: {N}/{Total} ({percent}%)
  - 소요 시간: {T}분
```

### 완료 후 보고

**템플릿:**
```
=== 프로덕션 작업 완료 ===

✓ 1단계: 번역 완료
  - {N}개 텍스트 → 5개 언어 완전 번역
  - XLT 엑셀: xlt/xlt_output_{timestamp}.xlsx
  - 검증: P0 0건, P1 {X}건, P2 {Y}건

✓ 2단계: 프로토타입 완료
  - {M}개 화면, {K}개 인터랙션
  - 프로토타입: index.html
  - 이미지: assets/screens/ ({M}개)

✓ 3단계: 위키 업데이트 완료 (선택)
  - Confluence 페이지 업데이트 완료

모든 작업이 프로덕션 품질로 완료되었습니다.
```

## 🔍 품질 보증 체크리스트

### Claude가 자체 확인해야 할 사항

**1단계 완료 후:**
- [ ] 모든 화면의 모든 텍스트 추출 확인
- [ ] 5개 언어 모두 번역 확인 (누락 없음)
- [ ] 3단계 검증 수행 확인
- [ ] P0 항목 0건 확인
- [ ] 엑셀 파일 생성 확인 (행 수 = 텍스트 수)

**2단계 완료 후:**
- [ ] 모든 프로토타입 화면 처리 확인
- [ ] 모든 인터랙션 매핑 확인
- [ ] 모든 텍스트 노드 매핑 확인 (data.js)
- [ ] 모든 XLT Key 매핑 확인 (i18n.js)
- [ ] 코멘트 포함 확인
- [ ] Variant swap 처리 확인

**3단계 완료 후:**
- [ ] 모든 화면 이미지 업로드 확인
- [ ] 전체 번역표 포함 확인

## ⚡ 긴급 중단 조건

다음 경우 작업을 중단하고 사용자에게 보고:

1. **데이터 손실 위험**
   - 일부 텍스트 추출 실패
   - 일부 화면 접근 불가

2. **불완전한 번역**
   - 일부 언어 번역 실패
   - 용어집 조회 실패

3. **검증 실패**
   - P0 항목 발견 후 수정 불가
   - 검증 스크립트 실행 실패

**중단 시 보고 템플릿:**
```
⚠️ 작업 중단

문제: {문제 설명}
영향 범위: {영향 받는 데이터}
진행 상황: {N}% 완료

다음 중 선택하세요:
1. 문제 해결 후 재시도
2. 현재까지 결과 저장 (불완전)
3. 작업 취소
```
